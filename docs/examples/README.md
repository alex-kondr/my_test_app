# Папка для еталонних прикладів агентів (Examples)

Сюди можна складати файли завершених та протестованих агентів.
Кожен новий файл у цій папці слугуватиме прикладом для ШІ-асистента.

### Рекомендовані назви файлів:
- `example_standard_review.py` — стандартний огляд з пагінацією, автором, датою, оцінкою та плюсами/мінусами.
- `example_listing_products.py` — приклад парсера лістингу товарів з характеристиками.
- `example_api_json.py` — приклад парсера, якщо дані надходять через внутрішній JSON API.
