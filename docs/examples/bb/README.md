# Еталонні агенти для сервера BB (Bazaarvoice / BigBrother)

- Папки агентів мають суфікс ` (BB)` (наприклад `hwtech.ru (BB)`).
- Скрипт завантаження: `upload_code_bb.py`.
- Відправка через SSH на віддалений сервер `agentdev1.eu.testfreaks.com` та запуск через `mockrun.py`.
- **Особливість імпортів:** модулі `re` та `simplejson` уже доступні в глобальній області видимості середовища BB за замовчуванням, тому писати `import re` чи `import simplejson` не потрібно.
- Сюди складаємо взірцеві файли агентів під сервер BB.
